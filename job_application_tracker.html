How to setup your Google Sheet & Docs in 2 minutes
  1. Open a blank Google Sheet at sheets.new.
  2. Click Extensions > Apps Script in the top menu of your Google Sheet.
  3. Delete everything in the code editor, and click the button below to copy the ready-to-use script.
  4. Paste the code, click Deploy > New deployment, select Web app, set Who has access to Anyone, and click Deploy.
  5. Copy the Web App URL generated by Google and paste it above!

Already connected? Copy the updated script below into your existing Apps Script project, then use Deploy > Manage deployments > Edit > New version > Deploy.
